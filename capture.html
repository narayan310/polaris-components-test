Polaris capture sheet

One frame per variant. Each caption is already in Figma's variant format (Property=Value, Property=Value): name the captured frame with it, make it a component, then select all frames in a set and choose Combine as variants. Figma reads the properties from the names.

Overlays (modal, popover, menu, tooltip) only render when open, so capture those from the components page.

To build native Figma components: export this sheet and load the file in the Polaris Foundations plugin. Import the foundations first so the components can use your variables and text styles.
